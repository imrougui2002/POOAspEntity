# POOAspEntity

Solution du TP .NET (ESP, 2026/2027).

- **P5AspEntity** : API minimale ASP.NET Core avec Entity Framework Core et SQLite (module Microsoft Learn « Utiliser une base de données avec une API minimale, Entity Framework Core et ASP.NET Core »).
- **P8Maui** : application .NET MAUI « Phoneword » (module 1 du parcours Microsoft Learn MAUI).

## Remarque sur P8Maui

Le projet a été développé sur un Mac sous macOS 11, qui ne permet pas d'installer .NET MAUI. La compilation est donc vérifiée par GitHub Actions sur une machine Windows (onglet **Actions** du dépôt). L'application n'a pas été exécutée à l'écran.
